# Assets Folder

This folder contains app icons and splash screens.

## Required Assets

Create these files for production:

1. **icon.png** - 1024x1024px app icon
2. **splash.png** - 1284x2778px splash screen
3. **adaptive-icon.png** - 1024x1024px (Android)
4. **favicon.png** - 48x48px (Web)

## Quick Setup

For now, you can use placeholder images or generate them using:
- [Figma](https://figma.com)
- [Canva](https://canva.com)
- Expo's asset generator

## Temporary Solution

The app will work without custom icons, but you'll see warnings. Add your custom assets here when ready.
